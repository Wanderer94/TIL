## 📘 [알고리즘 노트] DFS / BFS 핵심 요약 & 실전 응용 가이드

### 1. DFS vs BFS 한눈에 비교

| 구분          | DFS (깊이 우선 탐색)                                                | BFS (너비 우선 탐색)                                 |
| ------------- | ------------------------------------------------------------------- | ---------------------------------------------------- |
| **주요 개념** | 한 노드에서 출발해 가질 수 있는 **가장 깊은 곳까지** 탐색 후 돌아옴 | 시작 노드에서 **가장 가까운 노드부터 차례대로** 탐색 |
| **자료구조**  | **재귀 호출 (또는 스택)**                                           | **큐 (`collections.deque`)**                         |
| **주요 용도** | - 모든 경로를 탐색해야 할 때<br>                                    |

<br>- 경로의 특징을 저장해야 할 때 | - **최단 거리 / 최단 경로** 문제<br>

<br>- 미로 찾기, 네트워크 거리 계산 |

---

### 2. 표준 파이썬 템플릿 (기본형: 인접 리스트)

#### 🌲 DFS (재귀)

```python
def dfs(graph, v, visited):
    # 1. 현재 노드 방문 처리
    visited[v] = True

    # 2. 인접 노드 순회
    for i in graph[v]:
        if not visited[i]: # 아직 방문하지 않은 이웃 노드라면
            dfs(graph, i, visited) # 더 깊게 들어감

```

#### 🌊 BFS (큐)

```python
from collections import deque

def bfs(graph, start, visited):
    # 1. 시작 노드를 큐에 넣고 방문 처리
    queue = deque([start])
    visited[start] = True

    # 2. 큐가 빌 때까지 반복
    while queue:
        v = queue.popleft() # 맨 앞 원소 꺼내기 (FIFO)
        for i in graph[v]:
            if not visited[i]:
                queue.append(i) # 큐에 넣는 순간
                visited[i] = True # 즉시 방문 처리! (중복 삽입 방지)

```

### 3. 실전 문제 적용할 때 바꾸는 3가지 스위치 💡

깜지 패턴을 외운 후, 실제 문제 환경에 맞춰 아래 **3가지 포인트**만 변형하면 어떤 문제든 적용할 수 있습니다.

#### ① 그래프 형태 변형: 2차원 격자(미로/지도) 탐색

- **기본형**: `for i in graph[v]:`
- **격자형 (상하좌우)**: `dx, dy` 테크닉 활용

```python
dx = [-1, 1, 0, 0]
dy = [0, 0, -1, 1]

for i in range(4):
    nx, ny = x + dx[i], y + dy[i]
    if 0 <= nx < N and 0 <= ny < M: # 지도 범위 내이고
        if not visited[nx][ny]:      # 방문 안 했다면
            ...

```

#### ② 방문 처리 변형: 단순 방문(`True`) $\rightarrow$ 최단 거리(`숫자`)

- **기본형**: `visited[i] = True`
- **최단거리형**: `visited[nx][ny] = visited[x][y] + 1` _(이전 거리에 +1 갱신)_

#### ③ 큐에 담는 데이터 변형: 단일값 $\rightarrow$ 튜플(좌표 및 상태)

- **기본형**: `queue = deque([start])`
- **격자/상태형**: `queue = deque([(0, 0)])` 또는 `queue = deque([(x, y, cost)])`

---

### ⚠️ 자주 실수하는 '클리셰' 주의점

1. **`popleft()` 스펠링/메서드 주의**: `pop(0)`은 $O(N)$이므로 쓰지 않고, 반드시 `deque`의 **`popleft()`** ($O(1)$)를 사용한다.
2. **BFS 방문 처리 시점**: 큐에서 꺼낼 때가 아니라, **큐에 넣을 때(`append`) 즉시 방문 처리**를 해줘야 큐에 중복 노드가 쌓여 메모리가 초과되는 것을 막을 수 있다.
3. **`deque([start])` 괄호 형태**: `deque` 선언 시 리스트 형태로 전달해야 에러가 안 난다 (`deque([1])` O, `deque(1)` X).
