# [BFS/심화] 미로 탈출과 벽 부수기 (프로그래머스/백준 Gold IV)

- 난이도: Gold IV / Level 3
- 풀이 시간: 15분
- 성공 여부: 자력 성공

## 1. 핵심 아이디어 (Key Insight)

- 이동 거리의 가중치가 동일(1)하므로 최단 경로를 구하기 위해 **BFS**를 선택.
- 단순 $(y, x)$ 좌표 방문 처리로는 "벽을 부수고 온 상태"와 "안 부수고 온 상태"가 서로를 방해할 수 있음.
- 따라서 `visited[y][x][broken]` 형태의 **3차원 방문 배열**을 선언하여 상태(State)를 분리 탐색함.

## 2. 시간/공간 복잡도 분석

- 시간 복잡도: $O(N \times M \times 2) = O(N \times M)$
  - 각 칸을 '벽 안 부숨', '벽 부숨'의 2가지 상태로 최대 1번씩 방문하므로 $N \times M$ 선형 시간에 통과.
- 공간 복잡도: $O(N \times M \times 2)$
  - 3차원 visited 배열 공간 사용.

## 3. 복습할 핵심 코드 (3차원 BFS)

```python
from collections import deque

def solution(n, m, board):
    dy = [-1, 1, 0, 0]
    dx = [0, 0, -1, 1]

    # visited[y][x][broken]
    visited = [[[0] * 2 for _ in range(m)] for _ in range(n)]

    queue = deque([(0, 0, 0)]) # (y, x, broken)
    visited[0][0][0] = 1

    while queue:
        y, x, broken = queue.popleft()

        if y == n - 1 and x == m - 1:
            return visited[y][x][broken]

        for i in range(4):
            ny, nx = y + dy[i], x + dx[i]

            if 0 <= ny < n and 0 <= nx < m:
                # 1. 빈 칸인 경우: 현재 broken 상태 유지하며 이동
                if board[ny][nx] == 0 and visited[ny][nx][broken] == 0:
                    visited[ny][nx][broken] = visited[y][x][broken] + 1
                    queue.append((ny, nx, broken))

                # 2. 벽인 경우: 아직 벽을 부순 적이 없다면(broken == 0) 부수고 이동(broken = 1)
                if board[ny][nx] == 1 and broken == 0:
                    if visited[ny][nx][1] == 0:
                        visited[ny][nx][1] = visited[y][x][0] + 1
                        queue.append((ny, nx, 1))

    return -1
```
