## 💡 핵심 화두 & 직관 (Intuition & Thought Process)

### 1. 카메라를 어디에 설치해야 가장 효율적인가?

- **화두:** 도로 위의 수많은 구간 중 어디에 카메라를 세워야 단 한 대의 카메라로 가장 많은 차량을 커버할 수 있는가?
- **결론:** 차량이 고속도로를 나가는 지점(진출 지점)에 설치해야 합니다. 진출 지점 직전까지 카메라를 만나지 못했다면, 이 차량이 나가기 직전에 카메라를 세우는 것이 뒤따라오는 다른 차량들과 겹칠 확률(커버리지)을 가장 극대화합니다.

### 2. 정렬의 기준은 진입 지점인가, 진출 지점인가?

- **화두:** `routes` 배열을 진입 지점(`x[0]`)으로 정렬해야 하는가, 진출 지점(`x[1]`)으로 정렬해야 하는가?
- **결론:** **진출 지점(`x[1]`) 기준 오름차순 정렬**이 필수적입니다. 진출 지점으로 정렬하면 "가장 먼저 도로를 빠져나가는 차량"부터 순서대로 검사할 수 있어, 카메라 위치 갱신 로직이 $O(N)$ 선형 스캔으로 명확하게 단축됩니다.

---

## 📌 풀이식 및 논리 조건 (Mathematical & Logical Formulation)

1. **차량 경로 정렬 조건:**

$$\text{routes} = \text{sort}(\text{routes}, \text{key} = \lambda x: x[1])$$

2. **카메라 설치 및 유지 조건식:**

- 현재 카메라의 위치를 $C$, 검사 대상 차량의 진입/진출 지점을 각각 $S_i, E_i$라 할 때:

$$\text{If } S_i \le C \le E_i \implies \text{이미 카메라 통과 (추가 설치 X)}$$

$$\text{If } S_i > C \implies \text{카메라 미통과 } \implies C \leftarrow E_i \text{ (새 카메라 설치, } \text{answer} \leftarrow \text{answer} + 1 \text{)}$$

---

## 1. 핵심 아이디어 (Key Insight)

- 진출 지점(`routes[i][1]`)을 기준으로 오름차순 정렬합니다.
- 카메라의 초기 위치를 고속도로 최소 진입 가능 범위보다 작은 값(예: `-30,001`)으로 설정합니다.
- 정렬된 차량을 순회하면서, **차량의 진입 지점(`routes[i][0]`)이 현재 카메라 위치보다 뒤에 있다면** 기존 카메라로는 찍을 수 없으므로 **해당 차량의 진출 지점에 새 카메라를 설치**하고 카운트를 올립니다.

---

## 2. 시간/공간 복잡도 분석

- **시간 복잡도:** $O(N \log N)$
- 차량 대수 $N \le 10,000$입니다.
- 진출 지점 기준 정렬 연산 $O(N \log N)$이 전체 복잡도를 지배하며, 정렬 후 1회 순회는 $O(N)$이므로 제한시간 내에 여유롭게 통과합니다.

- **공간 복잡도:** $O(N)$
- 정렬 시 필요한 메모리 및 입력 리스트 보관 공간 $O(N)$을 사용합니다.

## 3. 복습할 핵심 코드 (Template & Solution)

### 🔹 파이썬 정석 풀이 코드

```python
def solution(routes):
    answer = 0
    # 1. 차량이 고속도로에서 '나간 지점(진출 지점)' 기준으로 오름차순 정렬
    routes.sort(key=lambda x: x[1])

    # 2. 마지막으로 설치된 카메라의 위치 (초기값은 문제 범위인 -30,000보다 작게 설정)
    last_camera = -30001

    # 3. 정렬된 차량 이동 경로 순회
    for route in routes:
        start, end = route[0], route[1]

        # 현재 차량의 진입 지점이 마지막 카메라 위치보다 뒤에 있다면 (카메라를 만나지 못함)
        if start > last_camera:
            answer += 1          # 새 카메라 설치
            last_camera = end     # 해당 차량의 진출 지점에 카메라 위치 갱신

    return answer

```

## 4. 자주 하는 실수 & 오답 회고 (Mistakes & Reflection)

- **내 착각 / 실수 가능성:** `routes.sort()`를 인자 없이 기본 실행하면 진입 지점(`x[0]`)을 기준으로 정렬됩니다. 진입 지점 기준으로 정렬할 경우, 진출 지점이 엉켜 뒤쪽 차량의 범위 덮어쓰기 로직이 복잡해집니다.
- **교정 지침:** 구간 커버리지 및 회의실 배정류의 그리디 문제는 "종료 시점 / 진출 시점"을 기준으로 정렬하는 것이 표준 템플릿임을 항상 상기할 것 (`key=lambda x: x[1]`).
