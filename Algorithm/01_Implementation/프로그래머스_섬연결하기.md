## 💡 핵심 화두 & 직관 (Intuition & Thought Process)

### 1. 최소 신장 트리(MST)와 탐욕적 선택 (Greedy Choice)

- **화두:** 모든 섬을 연결하되 전체 비용을 최소화하기 위한 다리 선택 기준은 무엇인가?
- **결론:** 매 순간 "건설 비용(`cost`)이 가장 적은 다리"부터 우선적으로 선택해 나갑니다. 따라서 `costs` 배열을 다리 가중치($cost[2]$) 기준으로 **오름차순 정렬**하는 것이 출발점입니다.

### 2. 중복 연결 및 사이클(Loop) 방지

- **화두:** 선택한 다리가 이미 연결된 섬들 사이를 또 이어주는 무의미한 비용 낭비(사이클)인지 어떻게 판별할 것인가?
- **결론:** \* **Union-Find (정석):** 두 섬의 최상위 부모 노드(대표 집합)가 같은지 확인하여 동일 그룹이면 차단.
- **Set (간소화):** 이미 연결된 섬들의 집합(`connected`)을 유지하며, "다리의 한쪽 섬만 집합에 속해 있는 경우"에만 탐욕적으로 확장.

---

## 📌 풀이식 및 논리 조건 (Mathematical & Logical Formulation)

1. **간선 가중치 정렬 조건:**

$$costs = \text{sort}(costs, \text{key} = \lambda x: x[2])$$

2. **Set 기반 사이클 방지 및 확장 조건식:**
   다리 $e_i = (u, v, cost)$ 에 대하여,

$$\text{Select Edge } e_i \iff (u \in connected \land v \notin connected) \lor (u \notin connected \land v \in connected)$$

- $\text{both } u, v \in connected \implies \text{Cycle (Ignore)}$
- $\text{both } u, v \notin connected \implies \text{Disconnected (Defer)}$

3. **종료 조건 (Termination Condition):**

$$\vert{}connected\vert{} = N$$

---

## 1. 핵심 아이디어 (Key Insight)

- 모든 노드를 최소 비용으로 연결하는 **최소 신장 트리(MST)** 구하기 문제.
- 비용 기준 오름차순 정렬 후, `set`의 `in` 연산자($O(1)$)를 활용해 기존 연결망을 확장하는 다리만 탐욕적으로 채택함.

---

## 2. 시간/공간 복잡도 분석

- **시간 복잡도:** $O(E \log E)$
- $E$는 다리의 개수 (`len(costs)`). 비용 기준 정렬 연산 $O(E \log E)$이 전체 복잡도를 지배함.

- **공간 복잡도:** $O(V)$
- $V$는 섬의 개수 (`n`). 연결된 섬의 상태를 저장할 `connected` 집합 공간.

---

## 3. 복습할 핵심 코드 (Template & Solution)

### 🔹 [풀이 1] Set 기반 크루스칼 간소화 (추천 파이썬 스타일)

```python
def solution(n, costs):
    answer = 0
    # 1. 건설 비용(cost[2]) 기준으로 오름차순 정렬
    costs.sort(key=lambda x: x[2])

    # 2. 연결된 섬들을 관리하는 집합 (0번 섬부터 출발)
    connected = {costs[0][0]}

    # 3. 모든 섬이 연결(len == n)될 때까지 탐욕적 확장
    while len(connected) < n:
        for u, v, cost in costs:
            # 한쪽 섬만 연결 상태인 경우 (사이클 방지 및 영역 확장)
            if u in connected and v not in connected:
                connected.add(v)
                answer += cost
                break
            elif v in connected and u not in connected:
                connected.add(u)
                answer += cost
                break

    return answer

```

### 🔹 [풀이 2] 정석 크루스칼 알고리즘 (Union-Find)

```python
def find_parent(parent, x):
    if parent[x] != x:
        parent[x] = find_parent(parent, parent[x])
    return parent[x]

def union_parent(parent, a, b):
    a = find_parent(parent, a)
    b = find_parent(parent, b)
    if a < b: parent[b] = a
    else: parent[a] = b

def solution(n, costs):
    answer = 0
    costs.sort(key=lambda x: x[2])  # 비용 정렬
    parent = [i for i in range(n)]   # 부모 테이블

    for u, v, cost in costs:
        # 사이클이 발생하지 않는 경우에만 집합 합치기
        if find_parent(parent, u) != find_parent(parent, v):
            union_parent(parent, u, v)
            answer += cost

    return answer

```

## 4. 자주 하는 실수 & 오답 회고 (Mistakes & Reflection)

- **내 착각 / 실수 가능성:** `costs.sort()`를 인자 없이 실행 시 1차원 인덱스인 시작 섬 번호(`cost[0]`)를 기준으로 정렬되어 그리디 선택 조건이 파괴됨.
- **교정 지침:** 2차원 리스트에서 특정 원소 기준으로 정렬할 때는 반드시 `key=lambda x: x[2]` 구문을 명시할 것.
